# Описание полей

Формальная схема: [schema/registries.schema.json](schema/registries.schema.json) (JSON Schema draft 2020-12). Все 12 полей есть в каждой записи; если значения нет, стоит `null` (в CSV пустая ячейка).

## data/registries.json и data/registries.csv

Одна запись = один государственный реестр.

| Поле | Тип | Может быть null | Описание | Пример |
|---|---|---|---|---|
| `id` | строка | нет | Постоянный идентификатор реестра (латиница). Карточка на сайте: /r/&lt;id>/ | egrul |
| `short_name` | строка | нет | Короткое название, как его ищут люди | ЕГРЮЛ |
| `name` | строка | нет | Официальное полное название | Единый государственный реестр юридических лиц |
| `agency` | строка | нет | Ведомство, которое ведёт реестр (короткое название) | ФНС России |
| `law` | строка | нет | Основной нормативный акт: номер, дата, название, статья | 129-ФЗ от 08.08.2001 «О государственной регистрации юридических лиц и индивидуал |
| `year` | целое число | нет | Год появления реестра (по первому акту или запуску) | 2002 |
| `access` | строка, список значений | нет | Открытость: open (открыт всем), partial (частично), closed (закрыт для публики) | open |
| `has_api` | да/нет | нет | Есть API или платная машиночитаемая выгрузка | false |
| `has_opendata` | да/нет | нет | Есть набор открытых данных | true |
| `official_url` | URL | нет | Официальный сайт реестра | https://egrul.nalog.ru/ |
| `check_url` | URL | да | Где проверить запись на официальном сайте; null, если единой точки проверки нет | https://egrul.nalog.ru/ |
| `url` | URL | нет | Карточка реестра на reestr-reestrov.ru | https://reestr-reestrov.ru/r/egrul/ |

Значения `access`: `open` (искать и смотреть может любой бесплатно), `partial` (частично открыт), `closed` (закрыт для публики).

`has_api` и `has_opendata`: в JSON `true` или `false`, в CSV слова `true` и `false`.

CSV: кодировка UTF-8 с BOM, разделитель точка с запятой, перевод строки CRLF. Так файл сразу открывается в Excel с русской локалью.
